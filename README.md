# Glowfit Premium Responsive UI

Open `index.html` directly in a browser.

Files:
- index.html — complete semantic page
- style.css — responsive desktop/tablet/mobile design
- script.js — mobile menu, treatment slider, booking modal and nav interactions
- assets/ — visual assets cropped from the supplied reference image

The page is intentionally implemented as real HTML/CSS/JS rather than a flat screenshot.
Replace the cropped reference assets with the client's original high-resolution photos before production.
